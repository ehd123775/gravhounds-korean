# gravhounds-korean
GRAVHOUNDS 한국어 번역 패치

적용 방법
1. GRAVHOUNDS_KR_v1.0.3.zip을 다운로드합니다.
2. 압축을 풀고 WFO 폴더를 게임 폴더안에 복사해 덮어씁니다.
3. 게임 언어를 English로 설정하고 다시 시작합니다.
